# A Poem for the S3 Presigned URL Upload Project

---

## The Key That Opens the Cloud

A file awaits on the client's machine,
too precious to wander, too large to stream.
A request is sent through the API's gate,
where Lambda awakens to seal its fate.

In .NET it hums, on dotnet eight,
a function that signs with serverless grace.
API Gateway stands at the door,
routing each call to the cloud's very core.

A presigned URL — a key for a day —
is forged in the backend and sent on its way.
The client receives it, no credentials in sight,
and uploads directly by digital right.

The S3 bucket opens its arms wide,
CORS configured, no request denied.
The file lands safely in storage so deep,
a serverless promise the cloud chose to keep.

Sam builds it, Sam deploys with a guide,
the Angular frontend stands faithful beside.
Delete with `sam delete` when the demo is done —
ephemeral infrastructure, cleanly begun.

So here stands the proof, the concept made real:
a presigned URL with serverless zeal.
No long-lived credentials, no server to mind —
just cloud-native elegance, perfectly signed.

---

*A tribute to clean, serverless architecture on AWS.*
